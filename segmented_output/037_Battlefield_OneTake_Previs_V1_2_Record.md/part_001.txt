# 《一镜到底战场白膜预演》V1.2 阶段记录

## 1. 版本状态
- 版本：V1.2
- 基线：V1.1（保留，不覆盖）
- 目标环境：Blender 5.2.x
- 时间轴：第 1—900 帧，30 FPS，30 秒
- 交付状态：Blender Python 场景生成脚本已完成；静态检查完成；Blender 实机运行待本机验收。

## 2. 本轮根据用户反馈落实的结构变化
1. 摄影机不再使用接近直线的场景串联路线，改为多段 S 形穿梭、左右急转、纵向俯冲、反向修正、侧闪、光轴滚转和实体框架穿越。
2. 开场摄影机高度提高至约 150m；最终高空视点提高至约 145m；连续地形范围扩大到约 X=-420—620m、Y=-320—320m。
3. 场景改为统一主时间轴。人物、飞机、炸弹、浮尸、烟尘、倒木、房屋爆炸、交接和冲锋均按全局时间持续运行，摄影机不触发场景开演。
4. 开场增加鸽子左前景滑翔、四架轰炸机两侧错位迎面接近，以及四枚航空炸弹的释放、初段/中段/末段下坠和分点爆炸。
5. 森林增加倒木压人、战友赶到、托举树干、伤员脱困动作；增加实体树木框架供摄影机穿越。
6. 梧桐沟增加门口背负伤员的女性、伤员、老式木杆光荣弹、拉环动作、日军环绕和爆炸碎片。
7. 黄草关河扩展为约 72m 宽河面，增加分散渡河群演、平躺/侧卧/俯卧浮尸、漂浮木料和水下避让空间。
8. 山谷入口增加自然岩石框架，摄影机从冲锋人群中后拉穿过框架并升空。
9. 提供地貌参考图打包机制；地形采用连续程序化高度网格，外围山脊和岩石山体扩展。

## 3. 摄影机路线节奏设计
- 高空建立 → 鸽子后方跟随 → 四机迎面交会 → 穿机/看炸弹释放 → 机腹近景 → 俯冲落地。
- 森林：左切绕树 → 右切穿空隙 → 贴近掩体 → 低位 S 弯 → 看倒木救援 → 穿越树木框架。
- 李行沟：下切 → 岩壁窄口 → 沟底反向弯 → 旋转修正 → 斜向转场。
- 梧桐沟：日军后侧跟拍 → doorway rear-oblique → 拉环/爆炸 → 倾斜穿碎片与烟尘。
- 河流：斜向入水 → 低位穿人群 → 急停 → 惯性后退 → 侧闪 → 绕浮尸 → 出水。
- 老孟：贴地推进 → 唯一一次约 180° 环绕 → 正面低机位英雄停留 → 直接后拉。
- 山谷：穿冲锋队伍 → 银行式横向修正 → 穿自然岩石框架 → 连续升空。

## 6. 风险与预防
- **高风险：** 连续地形高度与既有角色坐标未做自动贴地；首轮播放可能出现脚底轻微埋入/悬空。预防：在 Blender 中按镜头检查脚底，后续加 terrain-snap 修正。
- **高风险：** 多段银行和急转曲线的插值可能产生局部穿模或画面过度倾斜。预防：重点检查 116—220、244—322、378—398、458—476、700—762 帧；按播放结果微调关键点和 bank。
- **中风险：** 轰炸机、炸弹、鸽子同处空域，初次运行需要检查遮挡与相对比例。预防：先在 1—110 帧逐帧检查。
- **中风险：** 河面群演数量增加，RTX 3060 可先用视口实时播放；完整渲染前降低采样与分辨率。
